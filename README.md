# 🐝 BeeCuaca — Dashboard Cuaca

Dashboard cuaca berbasis web yang menampilkan kondisi terkini dan prakiraan 7 hari dari API publik **Open-Meteo** (gratis, tanpa API key), dengan pencarian kota di seluruh dunia.

## Fitur
- Pencarian kota (geocoding Open-Meteo)
- Cuaca saat ini: suhu, kondisi, kelembapan, kecepatan angin
- Prakiraan 7 hari: kondisi + suhu minimum/maksimum

## Teknologi
HTML · CSS · JavaScript (Fetch API) · REST API Open-Meteo

## Menjalankan
Buka `index.html` di browser (butuh koneksi internet untuk API), atau jalankan server statis apa pun (mis. `npx serve .`).
